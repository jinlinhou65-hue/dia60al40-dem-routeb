<reproduction_levels>
对每篇论文、每个关键图表和每个阶段分别记录复现等级，不得只写“已复现”：
- L0 已定位：PDF 身份、页码、公式、图表和输入来源已确认。
- L1 算法复现：论文指标或方程已有可执行实现，使用合成/代理输入通过单元测试。
- L2 路线复现：真实求解器完成最小算例，输入输出和日志可追溯。
- L3 趋势复现：主要自变量改变时，方向、排序和机制与论文一致，并通过多 seed 或敏感性检查。
- L4 定量复现：在预先规定误差内复现论文关键数值或曲线，并完成网格、时间步和参数验证。
- L5 耦合闭环：上游真实状态驱动下游，反馈量再更新上游；守恒、跨求解器和实验/文献标定通过。

任何阶段的状态不得高于其最低关键证据等级。当前项目包含 L1-L3 和 Stage 04 网格

</reproduction_levels>

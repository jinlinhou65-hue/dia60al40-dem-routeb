## 证明边界

该 run 在 Ubuntu runner 上安装固定版本的 NumPy、SciPy 和 Matplotlib，执行完整
`unittest` 集，并生成/验证四篇论文算法层产物。因为本提交新增的测试位于 `tests/**`，
它同时证明 Linux 能读取 Al 氧化膜来源 CSV、机器参数 JSON、归档输入哈希与声明边界。

该 run 没有运行 DEM、COMSOL 或氧化膜离线网络结果计算。它证明预注册合同可移植、
测试通过，不证明任一破膜比例或氧化膜电阻已经实验标定。

Node.js 20 runtime 被平台强制迁移到 Node.js 24。该警告未导致步骤失败，也不改变
CSV/JSON 或测试结论；后续维护 workflow 时应升级相应 action major version。

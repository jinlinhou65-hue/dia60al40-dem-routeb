# Pressure-resistance calibration contract evidence

Status: `awaiting_real_experiment_data`  
Calibrated: `false`

This folder is generated by running the strict empty experiment template through
`scripts/calibrate_pressure_resistance.py`. A successful run proves that the schema, configuration,
archived partial-rupture curve and output contract are readable. It does not prove that an
experiment exists or that `f_m(P, history)` has been identified.

Files:

- `validation_report.json`: schema field count, row count and observed data origins.
- `calibration_summary.json`: explicit no-data decision and claim boundary.
- `condition_results.csv`: result header with no fabricated conditions.
- `report.md`: human-readable no-data result.
- `evidence_manifest.json`: implementation, input and output SHA-256 values.

Real measurements must be stored outside this reference folder until reviewed for provenance and
privacy. They must use the schema in `data/source/pressure_resistance_experiment_schema.json` and a
separate filled calibration config with an independently sourced specimen scale factor.

## 3. 来源结论

Lienhard 等对球形 Al 微粉的 XPS/TEM 表征给出常态约 `5-6 nm` 的钝化层；潮湿处理
可增加约 `3 nm`。这支持每个颗粒 `5/6/8 nm` 的有界厚度扫描，但其冷喷冲击破膜
机制不能转化为本准静态压制算例的破膜比例。

Persson 的薄膜接触理论给出 `R_f=rho_f d/A`，并指出完整 Al 氧化膜即使考虑隧穿，
通常仍远高于金属收缩电阻，除非膜破裂、存在缺陷或形成金属通道。Cyster 等进一步
证明 AlOx 的厚度、密度和化学计量变化会使电阻面积呈指数敏感并形成局部导电通道。
因此主不确定量必须是“金属微桥比例”，而不能继续用无物理来源的统一 `1/10/100`
电阻倍率替代氧化膜。

## 4. 冻结模型

令归档 Hertz 接触半径为 `a`，Al 电阻率为 `rho_Al=2.65e-8 ohm m`，单颗粒膜厚为
`d_p`，双颗粒有效膜厚 `d=2d_p`，名义 Hertz 面积 `A=pi a^2`。

### M0：clean 下界

```text
R_clean = rho_Al / (2a)
```

它只作为金属裸接触的低电阻边界，不代表真实粉末表面。

### M1：完整氧化膜边界族

```text
R_film = rho_f (2 d_p) / (pi a^2)
R_edge = R_clean + R_film
```

冻结 `d_p={5,6,8} nm`，`rho_f={1e6,1e9,1e12} ohm m`。`1e6` 与 `1e12` 是文献
讨论中的隧穿有效值和块体级筛查值，`1e9` 只是二者的对数中点；三者均不是压片
实验拟合值。

### M2：部分破膜主模型

令 `f_m` 为 Hertz 面积中等效金属微桥面积比例，并假定一条等效圆形微桥，因此其
半径为 `a sqrt(f_m)`。金属微桥和剩余氧化膜区域并联：

```text
G_metal = sqrt(f_m) / R_clean
G_film  = (1-f_m) / R_film
R_edge  = 1 / (G_metal + G_film)
```

冻结 `d_p=6 nm`、`rho_f=1e6 ohm m`，只扫描
`f_m={0,1e-12,1e-10,1e-8,1e-6,1e-4,1e-2,1}`。该网格是辨识跨越范围，
不是破膜概率或实验先验。不得根据结果温升选择“最佳” `f_m`。

Simmons 非线性隧穿公式暂不进入首轮网络计算，因为它需要逐边电压迭代和可靠势垒
参数；把缺失势垒静默补齐会造成比线性有界模型更强的虚假精度。

## 5. 网络和加载边界

对所有与上下电极共同连通的 Al-Al 分量求完整电阻网络：底电极 `V=0`，顶电极
`V=0.1 V`，内部节点满足 KCL。等效电阻由总电极电流得到。另将同一线性解缩放到
总电流 `1 A`，只用于验证固定电压和固定电流的相反发热方向。`1 A` 是归一化项目
边界，不是论文或实验电流。

必须分别报告完整网络等效电阻和加权最短路径，不得用五节点最短路径电阻冒充并联
网络等效电阻。每个场景输出逐边电压、电流、功率、排名和 top-5 热点。

## 6. 预注册验收门槛

1. 三个输入必须匹配预注册的原始字节哈希，或匹配仅将 CRLF/CR 换行规范化为 LF
   后的 canonical-LF 哈希；`96/115/50` 计数仍必须完全匹配，否则停止。
2. 不得新增推断接触，不得更改 Hertz 半径、电极节点或图拓扑。
3. 内部节点相对 KCL 残差和电源-逐边功率相对误差均不超过 `1e-10`。
4. 每条 M1 电阻不得低于对应 clean 电阻。
5. 随 `f_m` 增大，恒压总功率不得下降；恒流总功率不得上升。
6. 报告最短路径是否改变、等效电阻范围、瓶颈、top-5 热点和热点排名变化。
7. 用逐边 `|Delta V|/(2d_p)` 与 `4-5e8 V/m` 器件薄膜边界比较，但只标记
   `field_boundary_exceeded`，不得自动宣称机械破膜或真实介电击穿。
8. 结果状态最高只能是 `bounded_oxide_network_sensitivity_pass`；没有压片电阻实验
   前不得称为 calibrated，也不得把绝对温升送入 Stage 06 作实验预测。

## 7. 停止条件和最小实验

若哈希、KCL、功率守恒或单调性失败，先修正离线网络实现，不运行 COMSOL。若所有
数值门槛通过但 `f_m` 无来源，状态保持 `review`。将模型升级为实验标定至少需要：

- 同批 Al/diamond 粉末的 XPS 或 TEM 氧化膜厚度分布；
- 同一模具尺寸下压力-压片电阻曲线，并记录恒流/恒压、温度和保压时间；
- 卸载后的电阻回线，用于区分可逆收缩与不可逆破膜；
- 至少三次重复及试样几何，以换算体电阻和接触网络尺度。

本预注册提交后，唯一下一任务才是实现并运行上述归档图离线计算。

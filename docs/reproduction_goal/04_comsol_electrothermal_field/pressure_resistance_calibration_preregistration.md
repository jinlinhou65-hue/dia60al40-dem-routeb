# 压力-电阻实验数据合同与逆模型预注册

状态：`interface_preregistered_awaiting_real_data`  
冻结日期：2026-08-08

## 科学问题

未来同批 Al/diamond 压片实验能否在明确的试样尺度映射下，把压力、加载历史和实测
电阻约束为有效金属微桥面积比例 `f_m(P, history)`？本阶段只建立数据入口、拒绝规则
和逆模型接口，不生成实验数据，不重跑 DEM/COMSOL，不把现有 18 场景变成标定结论。

## 可辨识性边界

归档网络只有 96 个颗粒，其等效电阻不能直接等同于宏观压片电阻。定义

```text
R_specimen_corrected = s_R * R_archived_network(f_m)
```

其中 `s_R` 是试样尺度因子，必须来自独立几何上尺度、独立参考实验或预先冻结的校准，
并同时提供来源和相对标准不确定度。`s_R` 缺失时，无论 CSV 有多少电阻点，接口都必须
返回 `not_identifiable_missing_scale`。禁止用本批待反演电阻同时拟合 `s_R` 和每个点的
`f_m`，因为该问题欠定。

二线测量必须给出引线与电极接触电阻，并从实测值中扣除；四线测量该字段只能为空或
零。试样体电阻率 `rho=R A/L` 仅作为几何归一化报告量，不自动替代网络尺度因子。

## 数据门槛

1. 物理校准只接受 `data_origin=experiment`；`synthetic_test` 只能返回
   `synthetic_validation_only`。
2. 每个 `condition_id` 至少包含三个不同 `specimen_id`，不能把同一试样重复读数冒充
   独立重复。
3. Al 与 diamond 分数必须使用同一质量或体积基准，且和为 1。
4. 记录试样直径、高度、压力、加载/保压/卸载、时间、温度、电源模式、二线/四线、
   电压、电流、电阻、仪器、校准日期、操作者和排除标记。
5. 同时提供电压与电流时，`V/I` 与电阻的相对差不得超过 2%。
6. 加载压力按测量序号不得下降，卸载压力不得上升。
7. 每工况重复 CV 上限预注册为 10%；超限只能进入 `review_variability`。
8. 留一法相对残差上限为 10%；边界饱和、零桥区间或不确定度跨越未解析区间时返回
   `not_identifiable`，不得自动外推。

## 逆模型

只使用已归档 `partial_rupture` 网络曲线。对正 `f_m` 节点在
`log(R)-log(f_m)` 空间单调插值；`f_m=0` 与 `1e-12` 之间只报告区间，不制造对数点估计。
超出曲线电阻范围时报告上下边界饱和。置信区间结合独立重复 bootstrap 与尺度因子
不确定度；输出必须包含 CV、留一残差、边界标记和声明边界。

## 交付与停止条件

- JSON CSV schema、空模板和校准配置模板；
- 验证器与逆模型 CLI；
- 合成解析恢复、缺失尺度、重复不足、接线错误和内容拒绝测试；
- 空模板运行只能生成 `awaiting_real_experiment_data`；
- 在真实数据和独立 `s_R` 到位前，Stage 04 保持 `review`，不向 Stage 06 输出绝对温升。

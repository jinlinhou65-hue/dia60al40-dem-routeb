# 08 Integrated Report And Visualization

## 阶段目的

把所有阶段的证据整理成最终可读、可检阅、可视化的综合复现报告。这个阶段不
负责新增物理模型，而是负责把 Zhang、Yuan、Liu、Li 四条线统一起来。

## 最终报告应回答的问题

1. 四篇论文各自复现到了什么程度？
2. 哪些是算法层复现，哪些是真实 DEM/FEM/COMSOL 结果？
3. 哪些结果已经通过验收，哪些仍是 review？
4. DEM 接触状态如何影响电流和温度场？
5. 温度场和接触热源如何影响烧结和致密化？
6. 哪些软件路线是主线，哪些是平行替代？

## 最终验收矩阵

最终报告应使用三类状态：

| 状态 | 含义 |
|---|---|
| `pass` | 数据、图、趋势和验收均满足该阶段目标 |
| `review` | 数据完整，但与论文级目标仍有差距 |
| `fail` | 缺少关键数据、模型不收敛或趋势相反 |
